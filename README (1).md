# Pakistan Anime Web

### Video Demo: https://youtu.be/G83-49icCco

### Description:

Pakistan Anime Web is a front-end web prototype of a modern anime streaming platform specially designed for Pakistani users. The main idea behind this project was to create a localized anime streaming experience that feels familiar to Pakistani viewers. While most popular anime platforms are global, this project explores how a platform can be customized with a Pakistani identity, including support for local language dubbing concepts and a clean, culturally relevant interface.

The project is built purely with HTML, CSS, and JavaScript. No backend or real video streaming is implemented because the focus was on creating a complete and polished front-end experience. The goal was to design an interface that looks and feels like a real streaming service while keeping the code simple and well-structured.

### Project Overview

When a user opens the website, they land on the home page (`index.html`). This page acts as the main entry point and introduces the platform. From here, users can navigate to different sections of the website such as browsing anime, watching episodes, viewing anime details, or accessing the admin panel.

The browse page (`browse.html`) allows users to explore a collection of anime titles. It is designed like a catalog where users can look through available shows. The watch page (`watch.html`) is the video player interface where users would watch episodes. Even though real video streaming is not connected, the layout and controls are designed to look like a real player.

There is also a dedicated anime details page (`anime.html`) that shows information about a specific anime series. Finally, the admin dashboard (`admin.html`) provides an interface for managing content. This page was included to show how an admin might control the platform in a real-world scenario.

### Files and Their Purpose

- **index.html**: This is the landing page of the website. It contains the main navigation, featured content sections, and an overall introduction to the platform.
- **browse.html**: This page displays a list or grid of anime titles so users can browse and select what they want to watch.
- **watch.html**: This is the video watching interface. It includes a player area and related episode information.
- **anime.html**: This page shows detailed information about a particular anime series including description and related content.
- **admin.html**: A simple admin panel interface for managing the platform’s content and settings.
- **css/**: Contains all the stylesheets responsible for the look, layout, colors, and responsive design of the website.
- **js/**: Contains JavaScript files that add interactivity and dynamic behavior to the pages.
- **assets/**: Stores images, logos, and other media files used throughout the project.

### Design Decisions

One of the main design goals was to keep the interface clean and modern while making it feel suitable for Pakistani users. I chose a dark theme because most popular streaming platforms use dark interfaces, and it also helps the anime artwork stand out. The layout is responsive so that the website can be used on both desktop and mobile devices.

I decided not to use any frameworks like Bootstrap or Tailwind so that I could practice writing pure HTML and CSS from scratch. This helped me better understand how layouts, flexbox, and responsive design work. JavaScript was kept minimal and only used where interactivity was needed.

The inclusion of an admin page was intentional. Even though the project is front-end only, I wanted to show the complete structure of a streaming platform, including how content might be managed behind the scenes.

### Conclusion

Pakistan Anime Web is a complete front-end prototype that demonstrates how a localized anime streaming platform could look and function. It focuses on clean design, clear page structure, and a user-friendly experience. While it does not include real video streaming or a backend, it successfully presents the concept of a Pakistani anime platform with multiple pages and a professional-looking interface.

This project helped me practice building multi-page websites, organizing files properly, and creating a consistent design system using only HTML, CSS, and JavaScript.
